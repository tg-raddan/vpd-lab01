# Changelog

Все заметные изменения проекта «Введение в профессиональную деятельность. Лабораторная работа № 1».

## [1.0.0] - 2026-11-04

### Added

- Реализация единого задания на 13 языках: C, C++, Python, JavaScript, TypeScript, Java, C#, F#, Go, Rust, Bash, Prolog, Assembler (x86-64).
- Персонализированные исходные данные студента: ФИО, группа, номер в списке.
- Вычисление `student_id` и `control_value` во всех реализациях, кроме assembler.
- «Визитные карточки» языков: форматирование, f-строки, template literals, интерполяция, конвейер `|>`, pipe в Bash, правило Prolog и другие.
- Документация проекта в `README.md`.
- Настроен `.gitignore` для артефактов сборки.
- Git-история с feature-веткой `feature/bash`, слиянием, разрешённым merge-конфликтом и аннотированным тегом `v1.0.0`.

### Notes

- Assembler реализован для Windows x86-64 с GNU Assembler (GAS) из WinLibs MinGW-w64.
- В качестве совместимой реализации Prolog используется Trealla Prolog 3.14.50.
